# FIFA-World-Cup-Analysis-Dashboard-1930-2022-

The **FIFA World Cup Analysis Dashboard (1930–2022)** is an interactive Excel dashboard project designed to analyze historical FIFA World Cup data across tournaments, teams, goals, match stages, and winners.

This dashboard transforms raw football data into meaningful visual insights using:

- Pivot Tables
- Pivot Charts
- Interactive Slicers
- KPI Cards
- Dynamic Data Visualizations

The project provides a comprehensive overview of FIFA World Cup performance trends from **1930 to 2022**.

# 📊 Key KPIs

| KPI | Description |
|---|---|
| Total Tournaments | Total FIFA World Cup tournaments analyzed |
| Total Goals | Total goals scored across tournaments |
| Total Matches | Total matches played |
| Average Goals | Average goals scored |
| Sum of Total Goals | Aggregate tournament goals |
| Average of Total Goals | Average tournament goal count |
